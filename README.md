# 배트맨: 텔테일 시리즈 한국어 패치 개선판

**Batman: The Telltale Series**의 기존 한국어 패치를 보완한 비공식 개선판입니다.
기존 번역을 바탕으로 오역·미번역을 보완하고, 인물 관계와 장면에 맞는 말투·대화 흐름·선택지 표현을 다듬었습니다.

## 배포 상태

**v1.0 최종 검수 중입니다. 패치 파일은 아직 공개하지 않았습니다.**
검수 후 [Releases](https://github.com/Hello-Melo/batman-telltale-korean-patch/releases)에 압축 파일을 업로드할 예정입니다.

## 주요 수정 내용

| 구분 | 보완 내용 |
| --- | --- |
| 에피소드 1·2 | 확인된 오역·미번역과 뉴스 자막 미출력 문제를 중심으로 보완 |
| 에피소드 3 | 인물 관계에 따른 존댓말·반말, 직역과 선택지 표현, 대화 흐름 및 배경 연설의 자막 겹침 보완 |
| 에피소드 4 | 숫자 ID와 영어가 노출되는 일부 대사·상호작용 문구, 깨진 문자열·띄어쓰기, 청자에 맞지 않는 말투와 선택지 보완 |
| 에피소드 5 | 뉴스·후반 대화의 누락, 인물 간 말투와 선택지 표현, 엔딩 대화·선택지 및 통계 문구 보완 |
| 메뉴·UI | 메인 메뉴 공백, 그래픽 설정·누아르 모드 관련 누락 문구 보완 |
| 통계·기사·코덱스 | 선택 결과의 한국어 번역 연결, 기사·코덱스의 누락 본문, 엔딩 종합 통계의 빈 문구와 글자 색상 대비 보완 |
| 시작 화면 | 기존 팀왈도 로고를 유지하고 개선판 버전과 작업자 크레딧 추가 |

## 설치 방법

패치 공개 후 Releases의 배포 압축 파일을 사용해 주세요.

1. 게임을 종료하고, 교체할 기존 파일을 백업합니다.
2. 압축을 풀고 패치 파일을 게임 설치 폴더의 `Archives`에 복사하여 덮어씁니다.
3. 게임 언어를 영어로 설정하고 실행합니다.

검수 기준은 PC판 Build 4509569입니다. 다른 빌드와의 호환성은 확인하지 않았습니다.
상세 설치 범위는 배포 파일에 포함된 안내를 기준으로 합니다.
