# 배트맨: 텔테일 시리즈 한국어 패치 개선판

**Batman: The Telltale Series**의 기존 한국어 패치를 보완한 비공식 개선판입니다.
기존 번역을 바탕으로 오역·미번역을 보완하고, 인물 관계와 장면에 맞는 말투·대화 흐름·선택지 표현을 다듬었습니다.

## 배포 상태

**v1.0 배포 중입니다.**
패치 파일은 [Releases](https://github.com/Hello-Melo/batman-telltale-korean-patch/releases)에서 다운로드할 수 있습니다.

## 주요 수정 내용

| 구분 | 보완 내용 |
| --- | --- |
| 번역 | 에피소드 1~5에서 확인된 오역·미번역·깨진 문구를 보완하고, 어색한 직역과 대화 흐름을 다듬었습니다. |
| 대화·선택지 | 인물 간 관계와 상황에 맞춰 존댓말·반말 및 선택지의 말투와 표현을 정리했습니다. |
| 표기 | 인명·지명·직급 표기를 통일하고, 띄어쓰기와 문장부호를 정리했습니다. |
| 자막 | 일부 뉴스·주요 대사의 자막 미출력과 배경 대사의 자막 겹침 문제를 수정했습니다. |
| 메뉴·UI | 메뉴의 누락 문구와 기사·코덱스·통계의 번역 및 표시 문제를 보완했습니다. |

## 설치 방법

배포 압축 파일에 포함된 패치 파일을 함께 설치해 주세요.

1. 게임을 종료하고, 교체할 기존 파일을 백업합니다.
2. 압축을 풀고 패치 파일을 게임 설치 폴더의 `Archives`에 복사하여 덮어씁니다.
3. 게임 언어를 영어로 설정하고 실행합니다.

검수 기준은 PC판 Build 4509569입니다. 다른 빌드와의 호환성은 확인하지 않았습니다.

## 남김말

직접 플레이하며 검토했지만, 모든 선택 경로와 경우의 수를 테스트하지는 못했습니다. 미번역·오역이나 버그가 남아 있을 수 있습니다.

추가 번역이나 정기적인 수정은 예정하고 있지 않습니다. 다만 게임 진행에 지장을 주는 심각한 버그가 있다면 [Issues](https://github.com/Hello-Melo/batman-telltale-korean-patch/issues)에 남겨 주세요. 시간이 될 때 확인하고 수정을 검토하겠습니다.
